How to Use — Personal

A step-by-step guide to Successwa Personal.

Quick start (5 steps)

  1. Dashboard — Add your Income Statement from each employer: gross pay and the tax already withheld (PAYG).
  2. Entries — Log every work-related deduction as you incur it, and keep the receipt with it.
  3. Calculators — Use the vehicle and home office calculators instead of guessing; they apply the current ATO rates.
  4. Personal Tax Details — Fill these in so HELP/HECS debt and the Medicare Levy Surcharge are counted correctly.
  5. Tax Report — Read your estimate, then export a CSV or PDF for your tax agent.

Understanding each page

  • Dashboard — A live overview of income, deductions, and your estimated refund or amount owing for the current financial year.
  • Entries — Every income and deduction line. Add, edit or delete entries; use recurring entries for regular items (e.g. monthly union fees).
  • Tax Report — The full breakdown: taxable income, tax on income, Medicare levy, offsets, and PAYG already withheld.
  • Business Activity — If you're a sole trader, carry your net profit from Successwa Business here so it's included in your individual estimate.

Tools

  • Generate PDF Report — A clean summary you can send to your accountant.
  • Download Backup — Saves a backup file of all your data. Do this before clearing site data or changing device.
  • Free Up Space — Removes old financial-year data (your backup keeps a full copy).
  • Merge Backup Files — Combines data from other backup files into this tracker.

Your data is saved to your signed-in account, so you can restore it on another device. Keep a backup anyway.

Successwa stores your data in your browser. When storage gets full, follow these steps to keep things running smoothly:

1 · Save your data to a file

This creates a backup file including all details. Save it somewhere safe like Documents or your Desktop. You can restore it anytime.

2 · Free up space

Remove entries from old financial years. Your backup file (Step 1) keeps a complete copy — nothing is truly lost.

3 · Load backup from file

Restore your data from a previously saved backup file. This replaces all current data in this tracker. Save a backup of your current data first if you want to keep it.

★ Merge backup files

Combine entries from other backup files into this tracker without replacing what's here. You can select multiple files at once.

☁ Cloud (Successwa server)

Your data is saved to the Successwa server under your signed-in account, so you can restore it on another device.
